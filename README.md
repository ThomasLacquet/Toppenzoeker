# Toppenzoeker

Welke bergtop zie je? Richt je camera, laad een foto of bekijk het panorama. Namen en bergkammen worden over het beeld getekend, in de stijl van PeakFinder.

**Open de app:** https://thomaslacquet.github.io/toppenzoeker/

Tip: in Safari tik je op Deel › Zet op beginscherm, dan werkt ze als losse app.

- Terrein: AWS Terrain Tiles (Terrarium) voor je hoogte, het bergsilhouet, de kammen en de zichtbaarheid van toppen.
- Toppen: ~200 ingebouwde bekende toppen, plus alle benoemde toppen uit OpenStreetMap binnen 150 km.
- Camera, kompas en GPS werken alleen via https (GitHub Pages is https).
